# Repository Agent Notes

## Package Scope

- `packages/wpcamp-hub-plugin`: WordPress plugin package. Uses WordPress, REST API authentication policy, PHP, Composer, npm, `@wordpress/scripts`, `wp-env`, the WordPress AI Client/OpenAI provider for importer parsing, PHPStan, PHPCS, and GitHub Actions workflows in the root `.github/workflows` directory.
- `packages/wpcamp-hub-theme`: WordPress theme package with PHP template files and theme styles.

Use this repository as a starting point for a client-specific monorepo. After creating the new repository, update this README with per-client information such as project scope, setup notes, package details, environments, and useful links.

## Quickstart

1. Create a new repository from the template:
   <https://github.com/new?owner=Citation-Media&template_name=client-monorepo&template_owner=Citation-Media>

2. Add the client monorepo agent skill:

   ```bash title="Add the agent skill"
   npx skills add git@github.com:Citation-Media/client-monorepo.git
   ```

3. Start an agent and ask it to begin working on the repository.

Update installed skills from time to time:

```bash title="Update skills"
npx skills update
```

Keep this README brief. Replace this quick-start text with the current client information once the repository has been initialized.
